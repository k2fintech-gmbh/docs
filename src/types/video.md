## VideoFileMetadata

| Field                   | Type                                | Description                                                                                                                                                                                               |
|-------------------------|-------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `uid`                   | `string`                            | Unique identifier for the video                                                                                                                                                                            |
| `thumbnail`             | `string`                            | URL of the video thumbnail                                                                                                                                                                                 |
| `thumbnailTimestampPct` | `number` \| `undefined`             | Timestamp percentage for the thumbnail                                                                                                                                                                  |
| `readyToStream`         | `true`                              | Indicates if the video is ready to stream                                                                                                                                                                   |
| `status`                | `FileStatus`                        | Status of the video file                                                                                                                                                                                  |
| `meta`                  | `{ name?: string }` \| `undefined`  | Metadata of the video file                                                                                                                                                                              |
| `created`               | `string`                            | Creation date of the video                                                                                                                                                                               |
| `modified`              | `string`                            | Last modified date of the video                                                                                                                                                                           |
| `scheduledDeletion`     | `string` \| `null` \| `undefined`   | Scheduled deletion date of the video                                                                                                                                                                       |
| `size`                  | `number`                            | Size of the video file                                                                                                                                                                                   |
| `preview`               | `string`                            | Preview URL of the video                                                                                                                                                                                |
| `uploaded`              | `string`                            | Upload date of the video                                                                                                                                                                                 |
| `duration`              | `number`                            | Duration of the video in seconds                                                                                                                                                                          |
| `input`                 | `{ width: number, height: number }` | Input dimensions of the video                                                                                                                                                                           |
| `playback`              | `{ hls: string, dash: string }`     | Playback URLs for the video                                                                                                                                                                               |
